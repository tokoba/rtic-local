# `#[task]` によるタスクの定義

`#[task]` で定義されるタスクは、RTIC で作業を実行するための主要な仕組みです。

タスクには次のことができます。

* スポーンされる（現在または将来。自分自身によってスポーンされることもあります）
* メッセージを受信する（タスク間でメッセージを受け渡す）
* 優先度を持つことで、プリエンプティブマルチタスクを可能にする
* 必要に応じてハードウェア割り込みにバインドされる

RTIC では、「ソフトウェアタスク」と「ハードウェアタスク」を区別します。

*ハードウェアタスク* は MCU 内の特定の割り込みベクターにバインドされたタスクであり、ソフトウェアタスクはそうではありません。

これは、たとえばハードウェアタスクが UART RX 割り込みにバインドされている場合、その割り込みが発生するたびに
そのタスクが実行されることを意味します。通常は、文字を受信したときに発生します。

*ソフトウェアタスク* は、タスク内で明示的にスポーンされます。すぐにスポーンすることも、Monotonic タイマー機構を使ってスポーンすることもできます。 

以降のページでは、両方のタスクと、それぞれで利用できるさまざまなオプションについて見ていきます。
